Figure S3. We examined the fraction of admissible paired storm-block bootstrap draws (a,b) and the width of the conditional 95% bootstrap interval for the CONUS404BA–CONUS404 random-error SD difference (c,d). Left and right columns show core and expanded windows. Admissible fractions are displayed for sample-eligible study cells with saved bootstrap diagnostics. Interval widths, calculated as the 97.5th minus the 2.5th percentile, are displayed only on the retained paired EC subset. Both windows use common scales for the same quantity, without clipping retained values. We used the saved 5,000-draw estimates; this figure does not rerun resampling. The intervals are conditional on admissible EC solutions and are neither simultaneous spatial confidence bands nor a domain-wide significance test. Panel means are watershed-area weighted as in Figure S1. Gray denotes cells outside each displayed subset.
